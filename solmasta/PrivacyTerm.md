# Privacy Policy for ai-router

**Last updated:** July 26, 2026

ai-router (“the App”) is a tool created by Luke Dorsett that allows users to route API requests through a customizable interface. This Privacy Policy explains what information the App collects, how it is used, and how it is protected.

---

## 1. Information We Collect

### a. User-Provided Information
The App does not require users to create an account or submit personal information directly.  
If you choose to authenticate with Google, Google may provide basic profile information such as:
- Email address  
- Name  
- Google account identifier  

This information is used solely to enable authentication and access to Google APIs you explicitly authorize.

### b. API Request Data
When you use the App to route API calls, the App may temporarily process:
- Request payloads  
- Headers  
- Endpoint URLs  

This data is **not stored**, logged, or shared.

### c. Automatically Collected Information
The App may collect minimal technical information such as:
- Browser type  
- Device type  
- Basic usage metrics  

This is used only to improve functionality and reliability.

---

## 2. How We Use Information

Information is used only for:
- Authenticating your Google account  
- Executing API requests you initiate  
- Ensuring secure operation of the App  

We do **not**:
- Sell your data  
- Share your data with third parties  
- Use your data for advertising  

---

## 3. Data Storage

The App does **not** store user data on servers.  
All processing occurs in real time and is discarded immediately after use.

---

## 4. Third‑Party Services

The App interacts with:
- **Google APIs** (only with your explicit permission)  
- **GitHub Pages** (for hosting the App)  

Your use of Google services is governed by Google’s own privacy policies.

---

## 5. Security

We use industry‑standard security practices to protect data in transit, including HTTPS encryption.

---

## 6. Your Choices

You may:
- Revoke Google API access at any time via your Google Account settings  
- Stop using the App at any time
